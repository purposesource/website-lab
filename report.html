Report a problem with a record

Tell us when a registry entry, a badge or a certificate is wrong, misused or not what it claims.

New page · the address and the response target are still to be decided

What to report

  • A repository listed that is not under the licence.
  • A badge or the name used without permission.
  • A certificate that does not verify, or one shown by someone it does not name.
  • An organisation named as covered that is not covered.

What to include

The address of the record, what is wrong, and how you know.

Where to send it

Records, badges, certificates
hello@purposesource.orgUntil a dedicated address is decided.
Security problems
security@purposesource.org

What happens next

We answer within [response target to be decided]. An outcome that changes a record is published with the record.
